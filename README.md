# Lucky By wanatsarut

เว็บไซต์ส่วนตัวของโอม ลูกบอลทอง เซียมซีข้อคิด ราศี และหน้าเปิดชุดเลข ใช้การสุ่มอย่างเท่าเทียม ไม่ใช่ระบบทำนายผลรางวัล

## เผยแพร่

อัปโหลดไฟล์ภายใน ZIP ทับที่ราก repository เดิม รวมโฟลเดอร์ dist แล้ว Commit รอ workflow GitHub Pages ล่าสุดสำเร็จ ไม่ต้องแก้ .github/workflows/static.yml

`node build.mjs` สร้าง 6 หน้าใน dist ใช้ภาพพื้นหลังร่วมกัน และสร้าง HTML standalone สำหรับเปิดดูในเครื่องในโฟลเดอร์แม่

## สิ่งที่บันทึก

ประวัติเครื่องสุ่มเก็บสูงสุด 200 รายการตามชื่อ แสดง 8 ครั้งล่าสุด หน้าเปิดชุดเลขบันทึกเลขล่าสุดพร้อมจำนวนครั้งในรายการเดียว จำกัด 3 ครั้งต่อวันเวลาไทย ใช้ Web Locks เมื่อเบราว์เซอร์รองรับเพื่อลดการกดพร้อมกันข้ามแท็บ ข้อมูลเก็บในเบราว์เซอร์เท่านั้น ผู้ใช้ล้างข้อมูลหรือเปลี่ยนเครื่องเพื่อเริ่มใหม่ได้ ไม่มีการยืนยันตัวบุคคล หากบันทึกไม่ได้ใช้หน่วยความจำชั่วคราวและแสดงข้อความแจ้ง

เสียงสร้างในเครื่องด้วย Web Audio ไม่ใช้ไฟล์เสียงจากภายนอก ปิดไว้เริ่มต้น โหมดแสงเบาและระบบ reduced motion ลดเอฟเฟกต์ หน้าเกี่ยวกับโอมรวมคำอธิบายข้อมูลส่วนตัว ไม่มีบริการติดตามโฆษณาหรือฟอนต์จากเว็บไซต์อื่น

## ทดสอบ

`npm test` ตรวจการสุ่ม ศูนย์นำหน้า ชุดไม่ซ้ำ วันตามเวลาไทย ขีดจำกัดสามครั้ง การเก็บเลขล่าสุด และข้อมูลบันทึกผิดรูปแบบ

`python3 -m http.server 4187 --directory dist` เปิด preview แล้วเข้าหน้า index.html

## รุ่น 3.2 — พื้นหลังและหน้าจอปรับขนาด

เลือกพื้นหลังประจำวันหรือเลือกเองในตั้งค่า พื้นหลังคำนวณตามวันเวลาไทยเมื่อเปิดหน้า ไม่สลับกลางการใช้งาน มีภาพต้นฉบับในชุดเว็บ 4 แบบ ไม่โหลดรูปหรือฟอนต์จากเว็บอื่น ทุกหน้าออกแบบให้ไหลตาม viewport มี safe-area, dynamic viewport height และโหมดแสงเบา จอพับสองส่วนใช้กฎเฉพาะเมื่อเบราว์เซอร์รายงาน viewport segments หากไม่รองรับจะใช้เลย์เอาต์ responsive ปกติ ไม่ใช่ใบรับรองว่าใช้ได้ครบทุกอุปกรณ์

## รุ่น 3.3 — เขย่าโทรศัพท์

กดปุ่มโทรศัพท์ก่อนเปิดเซนเซอร์ ขอ DeviceMotionEvent.requestPermission เฉพาะเมื่อมี API และกดโดยผู้ใช้ ใช้ค่าความเร่งสามแกน ตัดแรงโน้มถ่วงเมื่อจำเป็น นับ 6 จังหวะโดยมี hysteresis และ cooldown ป้องกันนับแรงค้างซ้ำ หยุด listener เมื่อครบ เมื่อกดหยุด เมื่อซ่อนหน้า หรือเปลี่ยนหน้า ไม่ส่งหรือเก็บข้อมูลเซนเซอร์ ผลใบข้อคิดยังเลือกด้วย Web Crypto เท่าเดิม
