# Lucky Orbit

เว็บสุ่มเลขภาษาไทยแบบลูกบอล ใช้ Web Crypto และ rejection sampling เลือก 2/3/6 หลักได้ เลขศูนย์นำหน้าและเลขซ้ำเป็นผลลัพธ์ที่ถูกต้อง ชื่อใช้แยกประวัติบนเบราว์เซอร์เท่านั้น ไม่ใช่บัญชีผู้ใช้และไม่ใช่แหล่ง entropy

ทุกครั้งสุ่มแยกกัน แต่ไม่รับประกันว่าคนต่างกันจะได้เลขไม่ซ้ำกัน ไม่มีระบบจองเลขส่วนกลางและไม่มีการทำนายดวงหรือผลหวย

## ลองใช้งาน

เปิด `../lucky-orbit.html` ได้ทันที หรือรัน `npm run dev` แล้วเปิด http://127.0.0.1:4173

## อัปโหลด Netlify

เข้าสู่ระบบที่ https://app.netlify.com/drop แล้วอัปโหลด `../lucky-orbit-netlify.zip` เพื่อเผยแพร่ ภายใน ZIP มี index.html ที่รากและไฟล์ CSS/JS พร้อมใช้งาน ไม่ต้อง build และไม่ต้องใช้ API key

ยังไม่ได้เผยแพร่โดยอัตโนมัติ: connector ไม่มี upload/deploy operation, เบราว์เซอร์เปิด file chooser ไม่ได้ และเครื่องไม่มี Netlify CLI authentication

เพิ่ม `.netlify/` ใน `.gitignore` แล้ว เพื่อไม่ให้ข้อมูลเชื่อมโยงโปรเจกต์ถูก commit หากใช้ CLI ภายหลัง

## ตรวจสอบ

`npm test` ตรวจ rejection sampling, ความถี่ที่เท่ากันของ accepted byte values, ศูนย์นำหน้า, รูปแบบผลลัพธ์ และการปฏิเสธแหล่งสุ่มที่ไม่ปลอดภัย

ประวัติเก็บรวมสูงสุด 200 รายการใน localStorage แสดง 8 รายการล่าสุดตามชื่อ ถ้าบันทึกไม่ได้จะเก็บชั่วคราวในหน้านี้ ใช้ Google Fonts สำหรับฟอนต์ไทย หากโหลดไม่ได้จะใช้ฟอนต์ระบบ
